SponsorBlock (optional)

LVOVD uses yt-dlp's built-in SponsorBlock integration. SponsorBlock is a community database of timestamps for sponsor reads, intros, outros, self-promotion, and similar segments. With Action set to Off, nothing is changed and SponsorBlock is not contacted.

Choose which community-identified segment types to mark or remove. These controls are shown only where LVOVD knows yt-dlp's SponsorBlock support applies.

Prepared files live only in your local temporary folder and are automatically cleaned up after about an hour while the server is running.
